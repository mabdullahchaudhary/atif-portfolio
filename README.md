## 🚀 About The Portfolio

A premium, highly responsive personal portfolio website designed to showcase projects, skills, and professional experience. Built with a focus on clean UI/UX, fast load times, and fluid animations.

**Key Features:**
* 📱 **Fully Responsive:** Adapts seamlessly to mobile, tablet, and desktop screens.
* ⚡ **Performance Optimized:** Lightweight architecture using vanilla JavaScript.
* 🎨 **Modern UI:** Styled entirely with utility classes for a sleek, modern aesthetic.

## ⚙️ Quick Start & Usage

This template is open source! You are free to clone, modify, and use this code for your own personal portfolio.

### 1. Clone the Repository
To get a local copy up and running, run the following command in your terminal:

```bash
git clone https://github.com/mabdullahchaudhary/atif-portfolio.git
```

### 2. Open the Project
No package installation or `npm install` is required. 
* Simply open the `index.html` file directly in your web browser.
* **Pro-tip:** Use the **Live Server** extension in VS Code for hot-reloading.
